# assembly-calculator
Here's a story : i have assembled a calculator together.
Anyway
This was created on linux so don't be surprised if the executable doesn't work for you
Now i have attached a .txt file so anyone can take a look
And just so you know
I asked an AI to organize the code and i'm using intel syntax
These 2 ensure that you don't lose your mind when reading the code
This calculator does + , - , * , & , | and ^ (that's xor for those who don't know) 
And also ~ (which is NOT) and - to negate


How to use:
for  + , - , * , & , | and ^  , add your first number as the first argument , then the operation symbol you want , then the second number
as for ~ and - , the operation symbol as the first argument then the number as the second argument

Important:
Make sure to space the arguments out
